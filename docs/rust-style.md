# Rust style guide

Living style for **imp-lab** crates. Shared Imp-aligned Rust conventions live in the imp-rs guide:

- [imp-rs `docs/rust-style.md`](https://github.com/silentorb/imp-rs/blob/main/docs/rust-style.md)

Follow that document for crate naming expectations, data vs functions, ownership, and error-handling rules. Lab-specific GUI guidance belongs in this repo’s docs, not as a divergent copy of shared Rust rules.
